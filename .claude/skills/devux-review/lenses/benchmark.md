# Lens: benchmark

You compare Nacre against the Claude Code app and the Codex app for the phase under review.

- Work from the affordance list in `rubric.md`, and add any newer features of those apps that you know of.
- For each affordance, answer three questions:
  1. Does Nacre have it? Cite the code or spec.
  2. Does it reach Ryder on the phone in a usable form? For example, a host tool that exists but turns
     into a generic Allow/Deny prompt counts as missing.
  3. Would it matter in this phase?
- Look hardest at what an agent harness already gives the agent, but Nacre drops or flattens on the way to
  the phone. Examples: plan mode, AskUserQuestion, structured choices, forks, rewind, subagent research.
- Also say where Nacre could lead. The phone, Needs you, beads, OpenSpec and decision cards are things the
  other apps don't have, so name what only Nacre could do.
- Return at most 12 findings, using the schema in `rubric.md`.
