Chats as cards

Each chat is a card in the drawer. The card shows what the chat is working on and how far along it is. Tap a card and it unfolds into the conversation. Fold it back and you see every chat again. New chat stays at the bottom of the column, so a second, third or fourth chat in the project is one tap away. Jobs works the same way, from the work's side. The legacy tab bar becomes an expressive connected button group.

Board with the drawer (try it)

Chats

  • Every chat in the project is a card. Chats that need you or are running come first, then the most recent.
  • A chat working toward something shows that job inside its card: the bead or spec, a wavy progress bar and where it stands. A chat with no work says "Conversation".
  • Tap a card to unfold it into the conversation. The other chats fold to slim rows above it, so you always see where each one is. The chevron folds it back.
  • New chat floats at the bottom of the list (Claude, with Codex in the menu), and it is also the last slim row while a chat is open.
  • Delete chat moves into each card's long-press menu.

Jobs

  • One card per piece of work (a bead, an epic or a spec), with progress and the chats working on it.
  • Tap to unfold the steps: round sections, tasks or beads, each with its state.
  • Open chat switches to Chats with that chat unfolded. Work with no chat offers Start a chat about this, which creates a chat with the item attached.
  • Finished jobs fold into a "Done" group at the bottom.

Expressive treatment

  • The connected button group replaces the tab row and its divider line.
  • Large-radius cards (24dp, 28dp when open) on tonal surface containers instead of flat list rows.
  • Shape-coded marks: a cookie shape for Claude, a rounded square for Codex. The shape turns slowly while the agent works.
  • Wavy progress indicators, emphasized titles, a split-button New chat, and a send button that morphs on press.
  • On the folded phone the same cards fill the screen: unfolded, a card is the full chat; folded back, it's the list.
